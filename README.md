# Lógica de Programação e Algoritmos com VisuAlg

Repositório criado para armazenar e organizar as atividades práticas desenvolvidos na faculdade usando a ferramenta **VisuAlg** (Portugol).

---

## Objetivo

O objetivo deste repositório é documentar meu aprendizado inicial em programação, demonstrando domínio dos conceitos fundamentais de lógica, algoritmos e estruturas de controle.

---

## Tecnologias e Ferramentas Utilizadas

- **Linguagem / Notação:** Portugol
- **IDE / Software:** [VisuAlg 3.0](https://visualg30.sourceforge.io/)
- **Controle de Versão:** Git e GitHub

---

## Conteúdos Praticados

Neste repositório você encontrará resoluções para exercícios envolvendo:

- Entrada e Saída de Dados (`escreva`, `leia`)
- Estruturas Condicionais (`se ... entao ... senao`)
- Laços de Repetição (`enquanto`, `para`, `repita`)

---

Como Executar os Códigos

1 - Faça o download e instale o VisuAlg.

2 - Clone este repositório no seu computador:

git clone https://github.com/renatorb642/logica_de_programacao_visualg.git

3 - Abra o VisuAlg, vá em Arquivo > Abrir e escolha qualquer um dos arquivos com extensão .alg.

4 - Pressione a tecla F9 para executar o código.
